# Healthcare frontend

React + Vite + Redux. See the [project setup guide](../README.md) for the backend, demo accounts and presentation walkthrough.

```powershell
npm ci
npm run dev
```

Open http://localhost:5173. Start the backend on port 5000 first. Vite proxies `/api` to the backend.

Checks: `npm test`, `npm run build`, `npm run lint`.
